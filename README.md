# 星光圣诞树

一个使用 Canvas 和 MediaPipe Hands 的轻量网页互动：食指带起火花，V 手势点亮霓虹，张手变成星球，握拳聚回圣诞树。保留原来的 1500 颗粒子与四种交互，没有引入前端框架。

## 使用

通过 HTTPS 打开页面，点击“开启摄像头”并允许访问；也可以点击“先看星光”，只欣赏动画。右上角可关闭摄像头。把一只手完整放在画面里，保持手势几帧再切换，避免过暗环境和手指相互遮挡。

摄像头图像只在浏览器本地处理，本页没有上传图像的代码。手势库和模型资源从 jsDelivr 加载，需要网络；摄像头需要浏览器支持、安全上下文和用户授权。

本地预览：

```sh
python -m http.server 8000
```

然后在同一台电脑打开 `http://localhost:8000`。手机访问电脑的普通 HTTP 局域网地址通常不能使用摄像头，请部署 HTTPS。GitHub Pages 可选择 main 分支的根目录；本项目不包含自动开启 Pages 的设置。

## 这次的小幅修整

- 深绿色与暖金色的轻量界面，改善启动提示和手机布局。
- 修正火花位移先被覆盖、导致惯性恒为零的问题。
- 坐标跟随视频的镜像与 cover 裁切，减少指尖火花偏移。
- 手势尺度采用相对距离，形态切换需连续三帧确认。
- 丢失手部检测时清理霓虹与运动历史，不突然制造远距离火花。
- 动画独立于摄像头推理，资源或摄像头失败仍可预览。
- 固定 MediaPipe 资源版本，补充权限、网络和设备错误提示及关闭清理。
- 针对高像素密度屏幕、窗口缩放与后台暂停作了处理。

## 检查

```sh
node --test tests/smoke.cjs
```

这些测试使用合成关键点和模拟摄像头，验证程序状态、坐标映射和失败恢复，不替代真实设备的识别精度测试。真实效果仍受光线、摄像头、浏览器与手部遮挡影响，不承诺所有环境零误识别。
